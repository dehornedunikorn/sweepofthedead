# DEAD SWEEP

A régi prototípus helyett tiszta lappal újraépített, mobilbarát túlélő-puzzle.

## Grafikai szabályok
- Kizárólag raszteres képek (PNG/WebP).
- Nincs SVG, inline SVG, canvas-rajzolás vagy CSS-sel készített saját illusztráció.
- Az assetek az `/assets/` mappában vannak.

## Jelenlegi játékmenet
- 10×10-es, véletlenszerűen generált túlélőpálya
- Fertőzöttek, ellátmány, kijárat
- Szomszédos veszélyeket jelző számok és jelölő mód
- Életerő, lőszer, élelem, kötszer
- Mobilra optimalizált vezérlés

## Indítás
Statikus weboldal, buildlépés és külső függőség nélkül.
